# dos-29-diplomas-projects
## Трекер заказов
Простой веб-приложение для трекинга статусов заказов. Позволяет добавлять заказы, изменять их статус и просматривать список всех заказов. Использует:
- Golang для backend сервера
- PostgreSQL для хранения данных
- RabbitMQ для передачи событий об изменении статуса

### Функционал
1) Авторизация сессиями (логин/логаут)
2) Просмотр и управление заказами через удобный веб-интерфейс
3) Добавление новых заказов, изменение статусов
4) Просмотр таблицы всех заказов с возможностью вернуться в админку
5) Использование RabbitMQ для событийной обработки
